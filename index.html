Purti Assistant: chatbot test page

This is an ordinary web page. The chatbot at the bottom right is the same one that will go on the Purti website. No login is needed. It is connected to the test (UAT) system, so nothing you do here reaches real customers.

How to test

  1. Click the chat button at the bottom right.
  2. Chat the way a buyer would: ask about projects, prices, location, or book a site visit.
  3. When asked for a mobile number, use a made-up one starting with 900000, for example 9000001234.
  4. Use New chat (↻ in the chat header) to start again.

When reporting a problem

  • What you typed, and what the chatbot replied.
  • The time, and a screenshot if possible.
